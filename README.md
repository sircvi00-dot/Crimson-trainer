# Crimson Powerforce Trainer

A personal practice app for the Master Duel "Crimson Powerforce" structure deck.

- Watch: auto plays the Soul Resonator combo on a duel field.
- Practice: you pick each next move; wrong picks show a hint.
- Deck: the full list with card art. Tap any card for its full text.

Card art and text load from the YGOPRODeck card database the first time you open
the app online, then stay cached on your device.

## Put it on GitHub Pages
1. On github.com, create a new public repository (for example `crimson-trainer`).
2. Choose "Add file" > "Upload files" and upload every file in this folder. Commit.
3. Open Settings > Pages. Under "Build and deployment", set Source to
   "Deploy from a branch", Branch to `main`, folder `/ (root)`. Save.
4. After a minute your app is at `https://YOUR-USERNAME.github.io/crimson-trainer/`.

## Install it
- Android (Chrome): open the link, tap the ⋮ menu, then "Install app" or "Add to home screen".
- Windows (Edge or Chrome): open the link, then click the install icon in the address bar,
  or menu > Apps > "Install this site as an app".
